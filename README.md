# DraftEdge Web V1

A mobile-first Progressive Web App (PWA) for live fantasy football draft tracking and dynamic position scarcity modeling.

## Included
- Live snake-draft pick tracking
- Dynamic VORP
- Position scarcity by remaining player pool
- Near-term positional drop-off
- Draft Score ranking
- Position filters and player search
- Automatic My Team tracking based on your draft slot
- Undo and reset
- Configurable teams, roster starters, flex, superflex, PPR, and passing TD scoring
- Local browser persistence
- Offline caching after first load
- Add-to-Home-Screen compatible

## iPhone installation
The files must be served from a website (HTTPS) for full PWA/Home Screen behavior.

Easy hosting options:
1. GitHub Pages
2. Netlify Drop
3. Cloudflare Pages

Once hosted:
1. Open the site in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open DraftEdge from the new icon.

## Notes
V1 includes a demonstration player pool and projection values. The next version should replace this with a complete 2026 player data set and a calibrated Value of Waiting model.
